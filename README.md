# Mezzo Maths Reality Builder

A Vite React TypeScript MVP where students solve practical mathematics questions and use each answer to build real-world objects in 2D, 3D-style, and VR-preview modes.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel settings

- Framework: Vite
- Install command: npm install
- Build command: npm run build
- Output directory: dist
